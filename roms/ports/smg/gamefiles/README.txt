Place your own Super Mario Galaxy disc image here: the USA/Canada release,
revision 0 (game ID RMGE01), as a single .rvz file (Dolphin's RVZ format; WIA
works too). Any filename works. ISO and WBFS images are not supported yet;
Dolphin can convert them to RVZ.

Launch the port afterwards. The first launch prepares the game on the device,
which takes a while and needs about 3.5 GB of free space. The disc image is
left in place; you can delete it once the game starts.
